Installation and updates

OpenCognit detects installed CLIs via your PATH and common install locations. If one is missing, the assistant shows the official install command. CLI updates come from the vendors themselves, not through OpenCognit.

Multiple accounts

For Claude Code and Codex you can add several accounts (e.g. work and private) — each with its own login. You choose the account when starting; when one hits its limit, OpenCognit detects and shows it.

Quota

The card at the bottom of the sidebar shows how much of your quota is used — from the CLI's own output, without any request to the provider.

Dictation

Speak your tasks instead of typing — hold Ctrl+Space, speak, release. Recognition runs locally on your computer.
