Settings

What you can configure in OpenCognit.

Open the settings with Ctrl+,. Search every section at the top left.

  • System — keep the computer awake while agents work; maximum number of parallel agents; check for updates automatically.
  • Custom instructions — apply to all threads and the conductor, e.g. “Answer in English”, “Use pnpm”, “Never push without asking”.
  • Appearance — light, dark or system; language German or English.
  • Notifications — a notice when an agent waits for you, optionally with sound.
  • Accounts — several accounts per CLI.
  • Limit detection — text patterns OpenCognit uses to recognize a reached limit.
  • Steering — when input is sent to a working agent.
  • Terminal — buffer size per session.
  • Guardrails — see below; plus “Threads: only ask for risky actions”, test light and snapshots before every agent round.
  • Data — how long the local event log is kept; delete everything.
  • License and About.

Guardrails

Rules every input to an agent is checked against (multi-line pastes line by line). Per rule choose:

  • Block — not sent
  • Approval — sent only after you confirm
  • Warn — sent, and you get a notice
