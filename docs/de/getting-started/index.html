Erste Schritte

OpenCognit installieren, CLIs einrichten und das erste Projekt öffnen.

Was du brauchst

  • Linux oder Windows
  • Mindestens eine Coding-CLI mit eigenem Zugang, z. B. Claude Code (Claude-Abo) oder Kimi Code. Weitere: OpenAI Codex, Gemini CLI, Hermes Agent (mit einem Modell-Anbieter wie OpenRouter).
  • git, wenn du die Git-Funktionen nutzen willst

OpenCognit liefert keine CLI mit. Es erkennt installierte CLIs automatisch; jede CLI aktualisiert sich weiterhin selbst (z. B. hermes update).

Installieren

Lade den Installer von der Website: unter Linux das AppImage (ausführbar machen und starten) oder das .deb-Paket, unter Windows den Setup-Installer.

Einrichtungs-Assistent

Beim ersten Start führt dich ein Assistent durch vier Schritte: Sprache und Design, Coding-Agenten, Datenschutz, erstes Projekt. Bei den Agenten zeigt er, welche CLIs gefunden wurden, startet bei Bedarf das Login und nennt für fehlende CLIs den offiziellen Installationsbefehl.

Erstes Projekt öffnen

Klicke auf + neben dem Raster, wähle einen Projektordner und eine CLI — der Agent startet direkt in diesem Ordner. Der Ordner wird als Workspace in der Seitenleiste angelegt.

Lizenz eintragen (optional)

Ohne Lizenz läuft die Kostenlos-Stufe (4 Agenten gleichzeitig, 2 Workspaces). Nach dem Kauf fügst du den Schlüssel aus der E-Mail unter Einstellungen → Lizenz ein. Siehe Lizenz & Updates.

Linux: Viele gleichzeitige Agenten beobachten viele Dateien. Meldet dein System „zu viele Dateien werden überwacht“, zeigt der Einrichtungs-Assistent den passenden sysctl-Befehl zum Erhöhen von fs.inotify.max_user_instances.

Einführung

OpenCognit ist die Desktop-Zentrale für deine Coding-Agenten — mehrere Projekte, mehrere CLIs, ein Fenster.
