Process

How it works

I · Install

Download for Linux or Windows. The setup assistant finds your installed CLIs and helps you sign in.

II · Open projects

Click plus, pick a folder, pick a CLI — the agent starts right in that project. As many projects as you like, side by side.

III · Let them work

Terminals in the grid or threads with approvals: you see every tool step, risky commands wait for your click.

IV · Keep track

The Cosmos shows live which agent reads or changes which file — and warns when two touch the same one.

V · Review & commit

Read the diff, comment lines, send them back to the agent — then commit and push, all inside the app.

More agents.
More control.

Starting several agents at once is something almost every tool can do today. OpenCognit makes sure they only do what they should — and that you always see what they are doing and what it costs.

Guardrails out of the box

Commands from Claude Code, Codex and Gemini run through your rules first: block, ask or warn. Before every commit, OpenCognit scans for keys and passwords.

Your CLIs, as they are

Every agent in its real terminal, with its own commands, plugins and logins — or as a thread where questions and approvals arrive as cards. All projects in one grid.

Orchestrator that reports back

Say what you want: the orchestrator puts the team together, hands out the tasks and comes back on its own as soon as everyone is done.

Usage in euros

Tokens of every CLI per project and model, with API equivalent and subscription savings — read from local logs, nothing leaves your machine.

Schedule

Agents work at set times, for example running the tests every morning and writing a short report. Anything risky waits for your approval.

Git & review loop

Review changes, comment lines and send them back — commit, discard, switch branches, pull and push without leaving the app.

Editor, terminal & search

Edit files, open a shell (Ctrl+J), search the whole project (Ctrl+Shift+F) — right next to your agents.

Several accounts per CLI

Work and private logins side by side. When a quota runs out, you see it — and switch to the next account.

Cosmos

Your project as a star system. When an agent reads or changes a file, a beam of light shows it — and conflicts become visible early.
