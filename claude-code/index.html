What you get

Claude Code as you know it,
with a control center around it.

I

Real terminals, not a wrapper

Every session is the real Claude Code CLI in its own terminal. Slash commands, CLAUDE.md, MCP servers and plugins work exactly as before.

II

Many sessions, one window

Grid or focus view. You see at a glance which session is working, which waits for you and which is done — and answer it right there.

III

A check on every Bash command

Before Claude runs a command, OpenCognit checks it against your rules: block, ask or warn. Commands are unpacked first (bash -c, eval, $(…)), and git commit is scanned for keys.

IV

Work and private accounts

Several Claude logins side by side, each with its own config folder. Your ~/.claude stays untouched.

V

Sessions survive a restart

Close the app, open it tomorrow: your Claude sessions come back and continue where they were.

VI

An orchestrator on your subscription

Say in one sentence what should happen. The orchestrator starts Claude sessions, hands out the work and reports back when they are done.

How it works

Three steps, no new account.

I

Install Claude Code

As usual, and log in with your Claude subscription.

II

Install OpenCognit

Linux (AppImage, .deb) or Windows. It finds Claude Code by itself.

III

Open a project

Start as many sessions as you need — or give the orchestrator one sentence.

Questions about Claude Code

Do I need an Anthropic API key?

No. OpenCognit starts the Claude Code you already have installed, with your own login and subscription.

Does OpenCognit change my Claude settings?

No. Sessions start with their own settings file for the command check; your ~/.claude stays as it is.

Does my code go anywhere else?

Only where Claude Code itself sends it. OpenCognit has no telemetry and no account — everything else stays on your computer.

Does it run on macOS?

Not yet. OpenCognit is available for Linux and Windows.

What does it cost?

Free with up to 4 agents and 2 projects. Pro is a one-time purchase — no subscription on top of your Claude plan.
