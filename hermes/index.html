Questions about Hermes

Does OpenCognit change my Hermes configuration?

No. Hermes starts with its own config folder that links to your real one; only the copy of the config file carries the check hook.

Can Hermes be the orchestrator?

Yes. Claude Code, Kimi Code and Hermes can conduct; you pick the CLI for each new chat.

Does the Usage page count Hermes?

Not yet — Hermes keeps no readable usage log.

Does it run on macOS?

Not yet. OpenCognit is available for Linux and Windows.

What does it cost?

Free with up to 4 agents and 2 projects. Pro is a one-time purchase — no subscription on top of your plan.
