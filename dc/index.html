Questions

Asked often.

What does OpenCognit cost?

€69 once — the first 50 buyers pay a launch price of €39.33. That includes 12 months of updates. The version you bought keeps working forever; for newer versions after that you can renew updates. The free version allows 4 agents at the same time and 2 projects — with all features.

Do I need an account?

No. Buy, install, paste the license key — done. The key appears right after payment and is checked offline on your machine. There is no OpenCognit account and no sign-in.

Do I need an AI subscription?

Yes — and we say so openly. OpenCognit drives the coding CLIs you already have: Claude Code, Kimi Code, OpenAI Codex, Gemini CLI or Hermes. Your existing plans and quotas are used; AI costs are not included.

Is my code safe?

OpenCognit runs entirely on your machine, sends no telemetry and has no cloud of its own. Only the CLI you use talks to its provider — exactly as if you ran it yourself. The only thing the app fetches is the version file for updates, without any identifier; you can switch that off.

Does it replace VS Code or Cursor?

For working with agents, yes: editor, terminal, project search, Git and review are built in. You can still keep using your usual editor alongside.

Which systems are supported?

Linux (AppImage and .deb) and Windows. macOS is planned.
